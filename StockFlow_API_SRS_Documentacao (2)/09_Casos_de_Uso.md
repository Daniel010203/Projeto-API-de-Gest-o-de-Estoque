# 9. Casos de Uso

## UC-001 — Gerenciar Produtos
**Atores:** Administrador, Sistema Externo.

Permite cadastrar, consultar, atualizar e desativar produtos.

## UC-002 — Gerenciar Categorias
**Atores:** Administrador, Sistema Externo.

Permite cadastrar, consultar, atualizar e excluir categorias quando as regras de integridade forem atendidas.

## UC-003 — Registrar Entrada
**Atores:** Operador, Sistema Externo.

Registra uma entrada de produto, cria a movimentação e atualiza o estoque.

## UC-004 — Registrar Saída
**Atores:** Operador, Sistema Externo.

Registra uma saída, verifica o saldo disponível, cria a movimentação e atualiza o estoque.

## UC-005 — Consultar Estoque
**Atores:** Administrador, Operador, Analista, Sistema Externo.

Permite consultar o saldo atual e identificar produtos com estoque baixo.

## UC-006 — Consultar Movimentações
**Atores:** Administrador, Operador, Analista, Sistema Externo.

Permite consultar o histórico de movimentações com filtros.

## UC-007 — Consultar Indicadores
**Atores:** Analista, Administrador, Sistema Externo.

Permite consultar indicadores consolidados de estoque.
