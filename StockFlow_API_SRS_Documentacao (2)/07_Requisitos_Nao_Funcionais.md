# 7. Requisitos Não Funcionais

## RNF-001 — Performance
A API deverá apresentar tempo de resposta adequado para operações comuns.

## RNF-002 — Segurança
A aplicação deverá possuir mecanismos de segurança, incluindo futuramente autenticação, autorização e controle de permissões.

## RNF-003 — Manutenibilidade
O código deverá ser organizado em módulos e possuir separação de responsabilidades.

## RNF-004 — Escalabilidade
A arquitetura deverá permitir evolução sem necessidade de reescrever integralmente a aplicação.

## RNF-005 — Testabilidade
As principais regras de negócio deverão possuir testes automatizados.

## RNF-006 — Documentação
A API deverá disponibilizar documentação OpenAPI/Swagger.

## RNF-007 — Portabilidade
A aplicação deverá poder ser executada em diferentes ambientes utilizando Docker.

## RNF-008 — Versionamento
A API deverá utilizar versionamento, inicialmente `/api/v1/`.
