# 1. Introdução

## 1.1 Projeto

**Nome:** StockFlow API  
**Tipo:** API REST para Gestão de Estoque  
**Versão:** 1.0

## 1.2 Descrição

O StockFlow API é uma aplicação Back-End desenvolvida em Python com FastAPI para gerenciamento de produtos, categorias, estoque e movimentações.

O sistema será desenvolvido seguindo princípios de Engenharia de Software, arquitetura modular, validação de dados, persistência em PostgreSQL, testes automatizados, documentação OpenAPI e containerização com Docker.

## 1.3 Finalidade

Este documento faz parte da Especificação de Requisitos de Software (SRS) e estabelece a base para o desenvolvimento, validação, testes e evolução do sistema.
