# 4. Stakeholders

Stakeholders são as partes interessadas no desenvolvimento ou utilização do StockFlow API.

## 4.1 Proprietário do produto

Responsável pela definição das necessidades do sistema, prioridades e validação das entregas.

## 4.2 Desenvolvedor Back-End

Responsável pela arquitetura, implementação, testes, manutenção e evolução da API.

## 4.3 Analista de Dados / BI

Consumirá dados da API para geração de indicadores, análises e dashboards.

## 4.4 Usuários operacionais

Utilizarão as funcionalidades de consulta e movimentação de estoque por meio de aplicações consumidoras.

## 4.5 Sistemas externos

Aplicações que consumirão os endpoints da API, como sistemas Web, Mobile, ERP ou plataformas de BI.
