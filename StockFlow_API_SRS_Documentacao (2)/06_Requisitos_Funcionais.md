# 6. Requisitos Funcionais

## RF-001 — Cadastro de Produto
O sistema deverá permitir o cadastro de novos produtos.

## RF-002 — Consulta de Produtos
O sistema deverá permitir listar e consultar produtos, com filtros por nome, SKU, categoria e status.

## RF-003 — Atualização de Produto
O sistema deverá permitir atualizar dados de um produto existente.

## RF-004 — Exclusão de Produto
O sistema deverá permitir exclusão lógica de produtos que possuam histórico de movimentações.

## RF-005 — Cadastro de Categoria
O sistema deverá permitir cadastrar categorias de produtos.

## RF-006 — Consulta de Categorias
O sistema deverá permitir consultar categorias e produtos associados.

## RF-007 — Atualização de Categoria
O sistema deverá permitir atualizar categorias existentes.

## RF-008 — Exclusão de Categoria
O sistema deverá permitir excluir uma categoria quando as regras de integridade forem atendidas.

## RF-009 — Entrada de Estoque
O sistema deverá permitir registrar entradas e atualizar o saldo automaticamente.

## RF-010 — Saída de Estoque
O sistema deverá permitir registrar saídas e atualizar o saldo automaticamente.

## RF-011 — Bloqueio de Estoque Negativo
O sistema não deverá permitir saída superior ao estoque disponível.

## RF-012 — Histórico de Movimentações
O sistema deverá manter o histórico das entradas e saídas.

## RF-013 — Consulta do Estoque
O sistema deverá permitir consultar o estoque atual dos produtos.

## RF-014 — Identificação de Estoque Baixo
O sistema deverá identificar produtos cujo estoque esteja abaixo ou igual ao estoque mínimo.

## RF-015 — Consulta de Movimentações
O sistema deverá permitir filtros por produto, tipo e período.

## RF-016 — Indicadores de Estoque
O sistema deverá disponibilizar indicadores como produtos ativos, estoque baixo, entradas, saídas e valor total do estoque.

## RF-017 — Paginação
Consultas de grande volume deverão permitir paginação.

## RF-018 — Ordenação
Consultas aplicáveis deverão permitir ordenação.

## RF-019 — Validação dos Dados
A API deverá validar os dados recebidos antes do processamento.

## RF-020 — Tratamento de Erros
A API deverá retornar respostas padronizadas para erros.
