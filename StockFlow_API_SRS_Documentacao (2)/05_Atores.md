# 5. Atores

## 5.1 Administrador

Responsável pela administração do sistema.

Principais ações:
- Gerenciar produtos.
- Gerenciar categorias.
- Consultar estoque.
- Consultar movimentações.
- Administrar usuários em versões futuras.

## 5.2 Operador

Responsável pelas operações de estoque.

Principais ações:
- Consultar produtos.
- Consultar estoque.
- Registrar entradas.
- Registrar saídas.
- Consultar movimentações.

## 5.3 Analista

Responsável pela análise das informações.

Principais ações:
- Consultar produtos.
- Consultar estoque.
- Consultar movimentações.
- Consultar indicadores.

## 5.4 Sistema Externo

Representa aplicações consumidoras da API.

Exemplos:
- Sistema Web.
- Aplicativo Mobile.
- ERP.
- Power BI.
- Dashboard.
- Outro serviço/API.
