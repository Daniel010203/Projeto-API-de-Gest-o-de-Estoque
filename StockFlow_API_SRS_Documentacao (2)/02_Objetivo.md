# 2. Objetivo

O objetivo do StockFlow API é disponibilizar uma API REST profissional para controlar operações de estoque.

## Objetivos específicos

- Cadastrar produtos.
- Gerenciar categorias.
- Registrar entradas de estoque.
- Registrar saídas de estoque.
- Consultar saldo de estoque.
- Manter histórico de movimentações.
- Identificar produtos com estoque baixo.
- Disponibilizar indicadores.
- Permitir integração com sistemas externos.
- Disponibilizar documentação automática da API.
- Possibilitar futuras integrações com BI, dashboards e Machine Learning.
