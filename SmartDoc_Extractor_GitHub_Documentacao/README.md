# SmartDoc Extractor
Plataforma Inteligente para Extração, Classificação e Processamento de Documentos.

Projeto IDP em Python para receber documentos, identificar formatos/tipos, extrair dados, validar, armazenar, consultar, exportar e gerar indicadores.

## Formatos
PDF, XML, XLS, XLSX, CSV, DOC, DOCX, TXT, JPG e PNG.

## Stack prevista
Python, Flask/FastAPI, PostgreSQL, SQLAlchemy, pandas, openpyxl, PyMuPDF/pdfplumber, ElementTree/lxml, python-docx, Pillow/OpenCV, OCR, Regex, Docker, RabbitMQ, Redis, pytest e Power BI.
