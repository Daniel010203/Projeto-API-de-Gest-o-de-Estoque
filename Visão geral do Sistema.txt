Visão geral do projeto

Nome: StockFlow API
Tipo: API REST para gestão de estoque
Linguagem: Python
Framework: FastAPI
Banco: PostgreSQL
ORM: SQLAlchemy
Validação: Pydantic
Migrações: Alembic
Testes: Pytest
Containerização: Docker
Documentação: OpenAPI / Swagger

Objetivo

Construir uma API REST capaz de controlar produtos, categorias, estoque e movimentações, permitindo posteriormente integrar:

sistemas web;
aplicativos;
Power BI;
dashboards;
sistemas ERP;
aplicações de análise de dados;
modelos de Machine Learning.
